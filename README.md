# 智服流｜企业客服与工单智能体工作台

一个面向企业客服场景的 AI 应用项目。系统结合本地知识库检索、大模型问答与工单流转，帮助客服快速回答常见问题，并将需要人工处理的问题转为可跟踪工单。

## 核心功能

- 知识库检索：从 Markdown 规则文档中检索相关内容
- 大模型问答：基于检索到的资料生成回答
- 回答可追溯：返回知识库来源，降低无依据回答风险
- 未知问题拒答：知识库没有覆盖时提示转人工客服
- 工单创建：支持客户姓名、订单号、优先级
- 工单管理：查看待处理、处理中、已解决状态
- 工单状态流转：支持从待处理更新为处理中或已解决
- 网页工作台：提供可直接演示的客服问答与工单管理界面

## 技术栈

- 后端：Python、FastAPI、SQLAlchemy
- 数据库：SQLite
- 大模型：OpenAI 兼容 API
- 前端：HTML、CSS、JavaScript
- 测试：pytest、FastAPI TestClient
- 版本管理：Git、GitHub

## 业务流程

```text
用户提问
  ↓
检索本地知识库
  ↓
大模型基于资料生成回答
  ↓
展示回答依据
  ↓
需要人工处理时创建工单
  ↓
更新工单状态：待处理 → 处理中 → 已解决
