# 智服流：企业客服与工单智能体工作台

## 1. 项目背景

中小企业的客服人员每天需要重复回答订单查询、退换货、发票、物流等问题。
规则分散在 FAQ、售后制度和产品文档中，人工查询慢，且无法持续统计高频问题和处理结果。

本项目要做一个可演示的 AI 客服与工单协作系统：
用户提出问题后，系统先从企业知识库中检索可靠资料；无法解决或需要人工处理时，自动创建工单，并保留回答依据与处理记录。

## 2. 目标用户

- 客服人员：快速处理常见咨询和复杂问题。
- 客服主管：查看高频问题、工单状态和 AI 处理效果。
- 企业用户：获得有依据、可追踪的客服答复。

## 3. 核心问题

1. 客服规则分散，人工查找耗时。
2. AI 可能“编答案”，需要回答来源和拒答机制。
3. 复杂问题需要转人工，但信息容易遗漏。
4. 管理者缺少 AI 是否真的节省时间的数据。

## 4. MVP 功能范围

### 4.1 智能问答

- 用户在聊天页面输入问题。
- 系统基于知识库回答。
- 每条回答展示引用的知识来源。
- 没有可靠资料时，明确说明“不确定”，而不是编造答案。

### 4.2 知识库管理

- 管理员上传或录入 FAQ、售后规则、物流规则。
- 系统将文档切分并建立检索索引。
- 支持按关键词或语义检索相关内容。

### 4.3 工单智能体

- 当问题需要人工处理时，AI 提取用户问题、订单号和紧急程度。
- AI 调用“创建工单”工具。
- 工单可以查看状态：待处理、处理中、已解决。

### 4.4 数据看板

- 展示咨询总数、知识库命中率、转人工率、工单完成率。
- 展示高频问题，帮助运营人员优化知识库。

## 5. 本期不做的内容

- 不直接连接真实微信、企业微信或抓取聊天记录。
- 不接入真实订单、支付或客户隐私数据。
- 演示阶段使用模拟订单数据和公开/自编的脱敏规则文档。

## 6. 成功标准

1. 可以现场演示“提问 → 引用知识库回答 → 创建工单”的完整流程。
2. 提问没有资料覆盖的问题时，系统能拒答并建议转人工。
3. Swagger 接口文档可用，核心接口有自动化测试。
4. 项目可通过 Docker 启动，最终提供 README 和演示视频。
